These are the faces Er-Con documents are set in. IT normally
installs them for everyone. If you need to do it yourself: select the .ttf files
in each folder, double-click, and click Install in Font Book.

Install Regular, Italic, Bold and Bold Italic for each of the three families.
That is what Office uses. Do not add other weights — Google's SemiBold files
register as a separate family ("Archivo SemiBold") and only clutter the menu.

All three are free under the SIL Open Font License, included in each folder.
