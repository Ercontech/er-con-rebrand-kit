# Er-Con Rebrand Assets

Everything you need to make Er-Con material. Keep this folder; it will be
refreshed when the brand changes.

## Start here

**Templates/** — `Er-Con Template.potx` for decks, `Er-Con Letterhead.dotx` for
letters. Start every one from these. The palette, the type and the logo are
already set, so you should never be picking a brand colour by hand.

The first four slides of the deck are reference material: the rules in short,
how to write the name, the brand colours and the chart colours. **Delete them
from any deck you send out.** They are at the front so you cannot miss them.

## The rest

**Er-Con Brand Standards.pdf** — the full guide. The live version is a web page;
this is a printed snapshot of it.

**Logos/** — every approved logo and icon, as SVG and PNG. Use the full-colour
logo on white, Mist and Straw; the Reverse logo on navy. The one-colour versions
are for single-ink printing, embroidery and engraving. Use an icon wherever the
full logo will not fit.

**Office Theme/** — only needed if the Er-Con colours are missing from your
colour menus. Double-click each file, or ask IT.

**Fonts to install/** — Archivo, Source Sans 3 and IBM Plex Mono. IT normally
installs these for you. If your documents look wrong, check these are in Font
Book first.

## Sending documents out

**Send a PDF.** File > Save as PDF, or Print > PDF. A PDF carries its fonts and
its layout inside it, so the recipient sees exactly what you sent, on any
machine, every time. Use it for anything final: letters, proposals, capability
statements, and any deck that only needs to be read rather than edited.

**Send an editable Word or PowerPoint file only when someone genuinely has to
edit it** — a contract being marked up, a deck someone else will present from.

When you do, **you do not have to do anything about fonts.** These templates
already have font embedding switched on, so the Er-Con faces travel inside the
file and the recipient sees the real thing even without them installed. That is
only true of documents started from these templates. A document begun from a
blank page carries nothing, which is one more reason to always start here.

## The name

**Write "Er-Con Technologies", then "Er-Con" after that.** Never "Er-Con
Technologies, LLC" on anything a client sees — that is for contracts only, and
even then only in the body and the signature block.
